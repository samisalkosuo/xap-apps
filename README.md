# XAP Apps

XAP Apps is a growing collection of small, focused applications created as a personal hobby project.

Each XAP application is independent, but they are built on the same shared framework and codebase. Common functionality, application structure and user interface components can be developed once and reused across the apps. This makes development simpler and, importantly, makes the applications easier to maintain and improve over time.

The idea behind XAP Apps is quite simple: I enjoy creating applications and experimenting with ideas that can become useful, focused tools. The aim is not to make every application large or feature-heavy, but to make each one do its particular job well.

All applications use the **XAP** prefix. It makes the family connection visible and provides consistent naming across the collection. There is also a practical reason: names in the App Store need to be unique, and the XAP prefix helps give each application its own identifiable name.

XAP Apps is a hobby project. Some applications may offer optional purchases to unlock additional features or capabilities. If you find an application useful, support through a purchase is always welcome and helps support continued development and maintenance.
