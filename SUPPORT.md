# XAP Apps Support

XAP Apps are designed to be small, focused, and hopefully simple enough that support is rarely needed. If you do encounter a problem, have a question, or would like to suggest an improvement, please open an issue in the [XAP Apps GitHub repository](https://github.com/samisalkosuo/xap-apps/issues). When reporting a problem, include the XAP application name, a short description of what happened, and, if possible, the steps needed to reproduce the problem so that I have enough information to look into it.
